# AC Briefing（AC 风格 Zeus 实时简报）

Zeus 在暗色战术地图上画线、标点，所有玩家全屏观看，同时在语音里听 Zeus 讲解。每一笔都以 Ace Combat 风格的动画呈现：线条延伸、图标弹出闪烁、威胁圈扩散。

- **客户端模组**：所有玩家（包括 Zeus）都要加载才能看到简报画面；**服务器不需要加载**，也没有任何服务器代码。没装的人看不到简报界面，但每个元素都会同步成原版地图标记（`acb_*`），按 M 照样能看到。
- 同步只用 `publicVariable`（公共变量由引擎直接转发，不经过 `remoteExec` / `CfgRemoteExec`），中途加入的玩家自动拿到当前画面。
- 依赖：**CBA_A3**。**ZEN** 可选（有的话 Zeus 右键菜单多一个入口）。可选联动 **Zeus 音乐播放器**（[fksans/ARMA3-ZUSE](https://github.com/fksans/ARMA3-ZUSE)）放 BGM。
- **兼容性**：0.4.0 的元素格式多一项（已摧毁）、颜色序号最大到 11，全队都要用 0.4.0；旧版客户端会看不对或报错。
- 设计文档：[DESIGN.md](DESIGN.md)（实现上的差异见末尾「实现说明」）。

## 怎么用

1. 导演任务开打前全队集合。Zeus 打开 Zeus 界面，按 **Ctrl+B**（或 ZEN 右键菜单「开简报主持」）打开主持界面。
2. 点 **▶ 开始简报**：所有玩家弹出全屏观看界面，先播开场（三声「嘀……」→ 画面从中心铺开），视角跟着 Zeus 走。可以在开始前先画好，开始后玩家直接看到画好的内容。
3. 边讲边画。玩家按 **Space** 在「跟随 / 自由查看」之间切换，Esc 关掉，简报进行中按 **Ctrl+B** 重新打开。
4. 讲完点 **■ 结束简报**，所有人的画面播放结束动画（黑幕合拢 → `DATA LINK TERMINATED`）后关闭。画过的内容留在地图上，打的时候按 M 还能看（见下面「原版地图标记」）。

### 原版地图标记（acb_*）

- 每画一个元素，立即生成对应的**全局原版标记**（名字 `acb_<id>`），删一个删一个，清屏全清。中途进服的人也能看到，简报结束后也不会消失。
- 对应关系：航线 → 折线标记（带箭头的线末端多一个 `mil_arrow2` 箭头）；区域 → 闭合折线；威胁圈 → 椭圆边框；图标 → 图标库里登记的原版标记类型和颜色（北约兵种标记按颜色换阵营：友军 b_ / 敌军 o_ / 其他颜色 n_），标签 → 标记文字。原版标记做不出虚线和填充，这两样在原版里显示为实线 / 只有轮廓。
- 颜色共 12 种：友军（蓝）/ 敌军（红）/ 注意（黄）/ 目标（绿）/ 白 / 橙 / 粉 / 棕 / 卡其 / 灰 / 独立 / 平民，每种对应一个原版标记颜色。
- **已摧毁**：原版标记变成灰色，图标文字加「（已摧毁）」。
- **装了模组的人**：在原版 M 地图、GPS 小地图、Zeus 地图、ACE MicroDAGR、cTab 上看到的是简报原样式（静态，不播动画、不出声；原版地图是白底，所以换成深色并加深色描边，简报界面里的样式不变），对应的原版标记在本机隐藏；**没装模组的人**看到的是原版标记。
- 只动 `acb_` 开头的标记（「一键清除」额外清掉旧版「转标记」留下的 `BRF_mk_*`），别人手画的标记、ACE 地图工具一概不碰。
- Zeus 每 10 秒自动检查一次，标记丢了（例如画的人掉线）就补上；也可以点工具栏 **重建标记** 手动重建。

### 指挥官标注

- 非 Zeus 玩家在简报进行中、观看界面里按 **D** 进入标注：可以用航线、目标点、威胁圈、区域、橡皮、Ctrl+Z、换色、箭头、测量尺、X 摧毁、Del 删除（橡皮 / X / Del 只能对自己画的），画的内容所有人可见，也同步成原版标记。Space 切换跟随 / 自由，Esc 回到观看界面；简报结束时自动关闭。
- 谁能标注：Zeus；小队长（队里不止他一个人）；编辑器里给单位初始化栏写了 `this setVariable ["BRF_canDraw", true];` 的人；Zeus 在 **权限** 面板里授权的人。被 Zeus 禁止的人不能（禁止优先）。其他人只能看。
- **权限** 面板（主持界面工具栏）：右侧列出所有玩家和当前状态，点一行在「自动 → 授权 → 禁止」之间切换，立即生效。

### 地图

暗色战术地图上自己画了一层青色的底图信息（主持端和观看端一样）：

- **地名**：首都、城市、村庄、小地名按缩放级别逐级出现
- **房屋**：放大到街区级别（1 像素 < 1.6 米）时显示建筑轮廓块，看巷战、搜房用
- **比例尺**：右下角，长度自动取整（100 M / 500 M / 1 KM ……）

### 图标库

目标点工具（2）一共 50 种图标：基础 4 种（目标 / 着陆区 / 起始点 / 航点）、**纯文字**（只显示标签，必须填文字），加上图标库 30 种（图形来自 [game-icons.net](https://game-icons.net)，CC BY 3.0，作者见 [docs/CREDITS.md](docs/CREDITS.md)）和「通用标记」15 种——

- **地面单位**：步兵、装甲、机械化、摩托化、炮兵、迫击炮、防空、侦察、狙击
- **空中 / 海上**：直升机、固定翼、无人机、舰船、登陆艇
- **设施**：指挥部、补给点、医疗点、雷达站、桥梁、机场、油库、通信站
- **战术标记**：集结点、撤离点、雷区 / 危险、观察哨、检查站、人质 / VIP、IED、伏击点
- **通用标记**：点、圆圈、叉、旗帜、目标圈、三角、方块、警告、未知、起点、终点、接应、会合、伏击、标记（对应原版 `mil_*`，和基础图形一样用程序绘制：跟随所有颜色、发光、白底描边、动画）

形状统一定义在 `tools/make_shapes.py`，它生成 `CfgShapes.hpp` 和缩略图 `ui/shapes/*_ca.paa`。

切到目标点工具时左侧出现图标面板，点一下选中；Tab 循环切换。图标面板和放点时标签输入框左边显示当前图标的缩略图（按当前颜色着色），地图上待确认的点显示真实图标。

**加图标**只需要改注册表 `addons/briefing/CfgIcons.hpp`（一个 class 一个图标：中文名、缩写、贴图、形状、类别、音效、**原版标记类型和颜色**）并放好贴图，不用改代码。原版标记类型或颜色缺失 / 游戏里不存在的图标不会被注册，RPT 里会有 `[BRF] icon '...' NOT registered` 的记录。

### 预案（像 PPT 一样分步展示）

简报前把内容画好、分好步，讲的时候按一个键展示一步，不用现场手忙脚乱地放图标。预案只在主持人本机、只在这一局有效。

| 按键 | 编排模式（P 进入 / 退出） | 播放（不在编排模式时） |
| --- | --- | --- |
| P | 进入 / 退出编排 | 进入编排 |
| N | 新建一步（记录当前视角） | — |
| [ ] 或 ← → | 切换正在编辑的步（地图跟着跳过去） | ← 撤回上一步，→ 播放下一步 |
| V / C | 用当前视角覆盖本步镜头 / 本步镜头开关 | — |
| Del | 删除本步（有内容时按两次） | — |
| Ctrl+Z · 清屏 | 只作用于预案 | 正常作用于实时内容 |
| X · 橡皮 | 悬停前面步骤元素按 X = 本步摧毁；用橡皮点前面步骤元素 = 本步移除（再操作一次取消） | — |
| Home | — | 撤回全部已播放的步 |

- 编排时画的东西只有你看得到：当前步亮显，前面的步淡淡显示。悬停前面步骤的元素按 X = 本步摧毁它，用橡皮点前面步骤的元素 = 本步移除它（再操作一次取消），编排视图里直接显示效果。
- 播放一步：这一步开了镜头、并且和当前视角差得比较多时，所有人的地图先飞过去，再一个接一个出元素；差不多时不飞。
- 播放到这一步时，先出本步元素，再依次执行这些动作；← 撤回时会恢复被摧毁 / 移除的元素。
- 撤回只移除元素，镜头不动。

### 主持界面

左键画，右键拖动平移，滚轮缩放。

| 键 | 工具 | 操作 |
| --- | --- | --- |
| 1 | 航线 | 左键拖拽画线；松开时按住 Shift = 只保留首尾成直线，按住 Alt = 虚线（流动的「行军蚂蚁」），画的过程中预览也跟着变成直线 / 虚线。A 切换末端箭头 |
| 2 | 目标点 | 左键单击放点，弹出输入框填标签（可留空），回车确认；Tab 切换图标种类（共 50 种，见「图标库」） |
| 3 | 威胁圈 | 左键按下定圆心，拖动定半径（实时显示米数），松开提交 |
| 4 | 区域 | 逐点单击，回车或双击闭合，Esc 取消 |
| 5 | 激光笔 | 按住左键，所有人看到红点跟随 |
| 6 | 橡皮 | 单击元素删除（悬停的元素会闪）；双击地图不放标记；编排模式下点前面步骤的元素 = 本步移除（再操作一次取消） |
| 7 | 测量尺 | 按住左键拖动，显示距离（米 / 公里）和方位（度 + 密位），带刻度；只在本机显示，不广播；下次测量、换工具或 Esc 清除。指挥官也能用 |
| 双击地图 | 原版地图习惯 | 任何工具下双击地图 = 放当前图标；区域工具双击仍是闭合区域，橡皮不放 |
| Ctrl+左键拖拽 | 原版地图习惯 | 任何工具下 Ctrl+左键拖拽 = 画线；Ctrl+Shift+拖拽 = 直线 |
| Del | 原版地图习惯 | 悬停元素按 Del = 删除（指挥官只能删自己画的） |
| X | 摧毁 | 悬停元素按 X = 标记为已摧毁（再按一次恢复；指挥官只能对自己画的） |
| Q / E | 颜色 | 下拉框 + 12 色：友军（蓝）/ 敌军（红）/ 注意（黄）/ 目标（绿）/ 白 / 橙 / 粉 / 棕 / 卡其 / 灰 / 独立 / 平民；Q / E 循环切换 |
| F | 聚焦 | 立即把当前视角推给所有人 |
| Ctrl+Z | 撤销 | 删除自己最后一个元素 |
| Ctrl+Shift+Del | 一键清除 | 3 秒内按两次：清除所有元素和所有 `acb_` 原版标记 |

状态栏显示「当前工具：… · 当前颜色：… · 当前图标：… · 当前状态：…」；观看端模式文字前加「当前：」。

**摧毁**：所有人看到：闪两下 → 图标和威胁圈上画红叉 → 渐变成灰色并保持，威胁圈停止脉冲，有音效 `destroy.ogg`。中途加入的人直接看到摧毁后的样子；原版标记变成灰色，图标文字加「（已摧毁）」。

工具栏另外有：**BGM** 下拉框（加载了音乐播放器时列出它的收藏，开始简报时全队淡入播放，结束时淡出）、**重建标记**（按当前内容重新生成所有 `acb_` 标记）、**权限**（标注权限面板）、**X** 关闭（简报不会结束，主持人回 Zeus 界面操作，再按 Ctrl+B 回来）。橡皮单击删除一个元素时，对应的原版标记也一起删掉。

**主持权**：同一时间只有一个主持人。别的 Zeus 在简报进行中打开主持界面时，会看到「接管 / 只看」。主持人掉线后画面不会丢，另一个 Zeus 接管后可以继续画，或者直接结束简报。

## 构建

和音乐播放器一样用 HEMTT（1.22.0 或更新）：

| 命令 | 作用 |
| --- | --- |
| `hemtt check -p` | 检查配置、SQF、stringtable |
| `hemtt launch` | 开发构建并启动游戏（自动加载 CBA；`hemtt launch zen` 再加 ZEN） |
| `hemtt release` | 正式构建 + 签名 + 打包 `releases/brf-<版本>.zip`（解压为 `@ac_briefing`） |

版本号在 `addons/briefing/script_version.hpp`。GitHub Actions（`.github/workflows/build.yml`）：PR / 推 main 时跑 `hemtt check`；推 `v*` 标签或手动运行时发布 Release（zip + `.bikey`）。签名方式（每版本一把 key / 固定 key）和音乐播放器 README 里「签名与 key」一节完全相同，只是前缀换成 `brf`。

## 进游戏测试步骤

代码已经按 DESIGN.md 的 M1–M7 全部写完，但**还没有进游戏实测过**。建议仍然按里程碑顺序验，前一步没过不往下走。出错时把 RPT 日志里的报错原样贴回来。

**M1 渲染（单机编辑器）**：编辑器里放一个玩家，预览，调试控制台执行 `[] call BRF_fnc_demo`。
应看到：全屏暗色青绿地图，左上角 BRIEFING；每隔 0.8 秒出现一个元素——蓝色曲线从起点延伸、线头有发光点、画完弹出箭头；黄色虚线在流动；绿色菱形从 3 倍大落下、闪 3 次（「滴」3 声）、标签逐字打出、四角括号缓慢呼吸；红色威胁圈从圆心扩散，之后每 2 秒一次脉冲；黄色区域按周长描边，再淡入填充。缩放地图时箭头、图标、标签保持固定屏幕大小。

**M2 主持输入（单机）**：编辑器里放一个 Game Master 模块并把自己设为它的 owner，预览，按 Y 进 Zeus，按 Ctrl+B。
应看到：手抖画出的线松开后变平滑；画线时按住 Shift 预览变直线、松开后是直线，按住 Alt 变虚线；工具 2 放点时出现输入框，回车后图标落下；Q / E 或颜色下拉框换色、Tab 换图标种类时状态栏变化。

**M3 多人同步（到这一步就能用了）**：两台机器（局域网两个实例，或上服务器找一个人）。Zeus 点「开始简报」。
应看到：对方弹出观看界面并播放 open 音效；Zeus 画一笔，对方 1 秒内看到同样的动画；点「结束简报」，对方画面淡出 1 秒后关闭。

**M4 视角 + 激光笔**：Zeus 右键拖地图、滚轮缩放 → 对方平滑跟随；按 F 立即同步；对方按 Space 切到自由查看能自己拖地图，再按一次回到 Zeus 的视角；工具 5 按住左键 → 对方看到红点顺滑移动，松开消失。
