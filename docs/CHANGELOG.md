# 更新记录

## 0.4.1

### 修复

- 玩家正在 ACE 军火库里配装时，Zeus 开始或接管简报会让军火库界面消失、人卡在军火库镜头里出不来，之后也再打不开军火库（重生也没用）。现在玩家开着军火库（ACE / 原版）、物品栏、暂停菜单或对话框时，简报画面先不弹出，聊天栏提示一句，关掉那个界面后再自动打开。
- 已经卡住的玩家：重新连接服务器即可恢复。

### 改动

- 另一个 Zeus 接管简报时，不再给玩家重新弹出简报画面：只有开始简报时才弹出。开着画面的人照常看（主持人名字会更新），已经自己关掉的人不会被拉回来，需要时按 `Ctrl+B` 打开。

## 0.4.0

> **兼容性**：元素数据格式变了（多了「已摧毁」状态、颜色最多到 12 种），**全队（包括 Zeus）都要更新到 0.4.0**，和 0.3.x 混用会显示不对或报错。服务器要换成 0.4.0 的 `.bikey`（创意工坊版用模组自带 `keys/` 里那份）。

### 新功能

- **12 种颜色**：工具栏的颜色按钮改成下拉框，在友军 / 敌军 / 注意 / 目标之外新增白、橙、粉、棕、卡其、灰、独立、平民。`Q` / `E` 照样循环切换。每种颜色都对应一个原版标记颜色。
- **15 个通用标记**：图标面板新增「通用标记」一组，和原版军用标记一一对应：点、圆圈、叉、旗帜、目标圈、三角、方块、警告、未知、起点、终点、接应、会合、伏击、标记。它们和简报里的其他图形一样用线条画出，跟随所有颜色、带发光和动画；没装模组的人看到的是对应的原版标记。图标总数 50 种。
- **缩略图**：图标面板的每一项、放点时标签框的左边都有缩略图（按当前颜色着色）；地图上待确认的点直接显示真实图标。
- **原版地图习惯**（任何工具下都能用）：
  - 双击地图放标记（区域工具里双击仍然是闭合区域）
  - `Ctrl` + 左键拖拽画线，`Ctrl` + `Shift` 拖拽画直线
  - 鼠标悬停在元素上按 `Del` 删除
- **测量尺**（工具 7）：拖动测量两点的距离和方位（度 / 密位），带刻度。只有自己看得到，不广播、不生成标记。
- **摧毁**：鼠标悬停在元素上按 `X`，元素闪两下、画出红叉、变成灰色并保持，威胁圈停止脉冲，附带音效；再按一次恢复。所有人可见，中途加入的人也能看到；原版标记同步变灰，图标文字加「（已摧毁）」。
- **预案互动**：编排时，后面的步骤可以对前面步骤的元素安排动作：悬停按 `X` = 这一步摧毁它，用橡皮点它 = 这一步移除它。播放到这一步时按顺序执行，按 `←` 撤回时被摧毁 / 移除的元素会恢复。

### 改进

- 画线时按住 `Shift` 预览就是直线、按住 `Alt` 预览就是虚线，和松开后的结果一致。
- 元素上限从 60 提高到 120。
- 状态栏改成「当前工具 / 当前颜色 / 当前图标 / 当前状态」，观看端显示「当前：跟随主持人视角」。
- 删除、清除、摧毁、预案这类按键按住不放只算按一下，避免一次按久了连删好几步。
- 程序图形的实心部分改为按地图坐标绘制，所有图形和面板里的缩略图一致。

### 给作者

- 程序图形的形状统一在 `tools/make_shapes.py` 里定义，它同时生成 `addons/briefing/CfgShapes.hpp` 和缩略图 `ui/shapes/*_ca.paa`。
- 新增音效 `sounds/destroy.ogg`（`tools/make_sounds.py`）。
- 原版标记颜色在启动时校验，类名不存在会退回 ColorBlack 并在 RPT 写 `[BRF] marker color ... is not in CfgMarkerColors`。
